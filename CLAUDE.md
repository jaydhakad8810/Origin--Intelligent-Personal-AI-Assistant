# CLAUDE.md

Rules for working in this repository.

## How to work

- Work on one small task at a time.
- Explain the plan before editing.
- Never invent requirements or make important decisions silently. Ask first.
- Inspect existing code before changing it.
- Preserve working code. No unnecessary rewrites or dependencies.
- Run the relevant tests and report the real output.
- Never claim a feature works unless it is implemented and tested.

## Git and secrets

- Never commit secrets.
- Never commit or push unless asked.

## Stack

- Web: Next.js + TypeScript + Tailwind + shadcn/ui
- API: Python + FastAPI + PostgreSQL + pgvector
- Agent: LangGraph (Phase 4)
- No Docker yet.

## User

- The user is a beginner. Give simple explanations.
